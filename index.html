Setup

This folder is the whole app. Put it on GitHub Pages, Netlify, or Cloudflare Pages, then open that https address in Bluefy.

  1. Create an app at developer.spotify.com/dashboard.
  2. Add the redirect URI below to that app. Copy it exactly.
  3. Open User Management and add the same Spotify account that plays the music. The dashboard does not add you on its own. Then sign out here and sign in again.
  4. Paste the Client ID here. Leave the secret out of this page.

If a song is playing and this page stays empty, turn off Private Session in the Spotify app and leave the song playing.

Last.fm

Last.fm can show the song without Spotify Premium. Create a free account, then in Last.fm open Settings, Applications, and connect Spotify Scrobbling. Turn Private Session off in Spotify. Create an API key at last.fm/api/account/create.
